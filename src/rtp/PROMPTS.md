# RTP artwork prompts

Generated with the built-in image tool, then fitted to the Minecraft menu with
nearest-neighbor scaling. Menu framing, captions and clickable regions are built
by `tools/rtp_assets.py`.

## Overworld

Minecraft-style pixel-art portrait for a random teleport dimension button.
A bright lush Overworld landscape with birch trees, a blue river, flowers,
grass blocks, mountains, sunshine and a small bee. Crisp chunky hard pixels,
no text, no UI frame, no labels. Fill the portrait canvas with the scene.

## Nether

Minecraft-style pixel-art portrait for a random teleport dimension button.
A dramatic Nether landscape with a lava river, basalt and netherrack, crimson
forest on one side, cyan warped forest accents on the other, and a small ghast.
Crisp chunky hard pixels, no text, no UI frame, no labels. Fill the portrait canvas.

## End

Minecraft-style pixel-art portrait for a random teleport dimension button.
The End with pale end-stone islands, tall obsidian pillars, purple chorus plants,
a dark violet sky and a small Ender Dragon silhouette. Crisp chunky hard pixels,
no text, no UI frame, no labels. Fill the portrait canvas.

## Region map

Wide 2:1 Minecraft-style pixel-art world map, all continents visible in their
recognizable geographic positions. Deep blue oceans, green blocky land,
tan deserts, pale mountains and snowy northern regions. Crisp hard pixels.
No pins, no text, no labels, no UI border. North America on the left and Europe
near the upper center, with clear space for two region markers.
